# Биодент+ — сайт стоматологии (г. Ош)

Одностраничный сайт-визитка. Next.js 15 + Tailwind v4 + TypeScript.

## Запуск

Нужен Node.js 20+ (https://nodejs.org, LTS).

```bash
npm install
npm run dev
```

Открыть http://localhost:3000

## Заявки в Telegram

1. Создать бота через `@BotFather`, получить токен.
2. Написать боту любое сообщение.
3. Открыть `https://api.telegram.org/bot<ТОКЕН>/getUpdates`, взять `chat.id`.
4. Скопировать `.env.example` в `.env.local` и заполнить.

Без переменных окружения форма работает, заявка пишется в консоль сервера.

## Подмена под другую клинику

1. `config/clinic.ts`, экспорт `clinic` — название, домен, контакты, услуги, врачи,
   отзывы, FAQ, цифры в hero, координаты для Schema.org
2. `config/clinic.ts`, экспорт `copy` — заголовки секций, подписи кнопок, лейблы
   полей формы. Трогать не обязательно, нужен при переводе на другой язык
3. `app/globals.css`, блок `@theme` — палитра
4. `app/icon.svg` — буква и цвет фавикона
5. `public/clinic/` — фотографии

В компонентах текста нет. Цены скрыты флагом `showPrices: false`.

## Видео на фоне hero

Включается парой путей в `config/clinic.ts`. Пустые строки — фон остаётся
сплошным зелёным.

```ts
heroVideo: "/clinic/hero.mp4",
heroPoster: "/clinic/hero-poster.jpg",
```

Сейчас лежит `hero.mp4`: 1280×720, 12.3 с, без звука, 1.17 МБ.

Требования к файлу — сайт открывают с телефона на мобильном интернете:

- 6–10 секунд, бесшовный цикл
- H.264, mp4, 1280×720 (за 75% затемнением больше не видно)
- **без звуковой дорожки** — иначе браузер не даст автозапуск
- `+faststart`, чтобы видео начиналось до полной загрузки
- цель — до 1.5 МБ

```bash
ffmpeg -i source.mp4 -t 8 -an -vf "scale=1280:-2,fps=25" \
  -c:v libx264 -profile:v high -crf 28 -preset slow -movflags +faststart \
  public/clinic/hero.mp4
ffmpeg -i public/clinic/hero.mp4 -frames:v 1 -q:v 4 public/clinic/hero-poster.jpg
```

Постер обязателен: он показывается, пока видео грузится, и вместо видео при
`prefers-reduced-motion`. Затемнение — `bg-brand-900/75` в `components/Hero.tsx`,
под конкретный ролик крутится этим числом.

Исходник в высоком качестве в `public/` держать нельзя — всё оттуда уезжает
на прод и качается кем угодно. Место монтажным исходникам — вне репозитория.
